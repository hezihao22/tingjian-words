# 听见单词

以听懂、看懂为目标的单词网站。电脑显示紧凑单词表，手机自动切换为触摸布局。

## 使用

在线地址：https://hezihao22.github.io/tingjian-words/

- 包含六级24本、考研42本、GRE5本、托福9本，共80本词书。
- 每50个词分一组，末组保留剩余词。
- 点击单词读三遍英文；整组播放为英文三遍、中文主要释义一遍。
- 听音选义隐藏英文，选择中文答案；答错或不知道的词加入复习。
- 看懂、听懂分别记录；支持自定义主要释义、导出和恢复学习记录。

## 安卓手机

建议使用 Chrome 或 Edge 打开上方网址，可通过浏览器菜单添加到主屏幕。
网站自带中英文 MP3 音频，完全不依赖手机系统语音包。首次播放需要联网，音频按需加载，不会一次下载整个音频库。
手机单词表在主要释义下方，以稍小字体完整显示词库的全部原始释义。
整组播放边听边加载，支持拖动时间轴和单词居中跟随。全部缓存后，后台及息屏播放更稳妥；仍受系统、浏览器策略影响。

## 用户名与多人使用

右上角用户名按钮可修改当前名称，或创建、切换独立本机用户。每个用户分别保存词书、分组、已看懂、听选结果、收藏、释义和播放设置。导出/恢复仅针对当前用户，导出文件名包含用户名。

升级后原有记录和 GitHub 绑定仍在“我的学习”档案中。你可在自己的电脑和手机 Edge 分别将它改成自己的名字，继续使用已有私有仓库同步，无需新建档案或重新绑定。仅原有档案可使用个人 GitHub 同步；新增档案不读取、不使用、不修改它的授权。标签页切换用户后，其他已打开标签页仍留在各自用户中。

只分享网址不会分享授权。其他人用自己的浏览器打开，即使填写同名，也无法取得你的记录。用户名和密码属于本机档案，不是跨设备统一账号，不会凭名字跨设备同步。同一个浏览器的使用者可切换本机档案；个人授权只保留在自己的设备。若其他浏览器曾绑定同一个进度仓库，应在那里断开绑定。

## 记录与数据

学习记录先保存在当前浏览器，支持导出/恢复 JSON。设置中的 GitHub 同步可绑定独立私有仓库：使用仅授权该仓库 Contents 读写权限的 Fine-grained token。手机和电脑分别绑定；授权默认仅在当前标签页会话中保留，也可明确勾选记住到个人设备。授权码不会写入进度 JSON、导出文件或公开源码。
同步按字段最近修改时间合并，保存已听懂、已看懂、收藏、自定义释义及其恢复动作、所选词书与分组；播放偏好留在各设备。修改后空闲约20秒同步，页面打开/回到前台时合并，前台每2分钟检查一次。关闭页面前可点立即同步。离线记录保留，恢复联网后重试。请保持设备时间准确。
私有仓库中的 progress.json 只在有变化时提交。首次需创建仓库并授权，GitHub 登录状态不会自动传递给 Pages 网站。

词书文件以静态JSON按书加载。源数据：[LinXueyuanStdio/DictionaryData](https://github.com/LinXueyuanStdio/DictionaryData)，2026-10-25获取，原Apache-2.0许可证随仓库保留。
本项目对其进行四类词书筛选、书内去重、原文件顺序保留以及中文首义提取。完整原释义仍保留；主要释义并非词频排名，可自行修改。
选定四类共涉及28,474条去重词汇，其中4,234条没有可用中文主要义项，多为短语、专名或源数据缺译。网站明确标注，仍可听英文；补充释义前不参与听选。
音频覆盖全部词库英文和已有主要中文释义，共47,228个文件（含两条试听）。由 Windows Zira 英文、Huihui 中文语音预生成，48kbps MP3；同一释义复用一份。手机仅播放音频文件。新编辑的中文若不在音频目录中，保留显示及听选，跳过该条中文朗读，并明确提示。

## 托管

这是纯静态网站，无需后端或付费语音服务。不使用同步时无需账号或授权码。
GitHub Pages设置使用 main 分支的根目录，`.nojekyll`保留原文件结构。
所有资源使用相对路径，也可部署在其他静态托管平台的子目录。

核心文件：`index.html`、`style.css`、`app.js`、`profiles.js`、`core.js`、`sync-core.js`、`sync.js`。静态词书位于 `data/books/`，MP3 位于 `data/audio/`。
本地可执行 `python -m http.server 8080`，再访问 http://localhost:8080 。

## 第七版：边听边加载与单词跟随

点击“播放本组”，先加载开头需要的录音并开始播放，后面的词同时加载。Chrome / Edge 使用原始压缩 MP3 连续缓冲，不再等手机解码、拼接整组 WAV。音频目录会在打开词书时提前加载。听过的录音缓存在当前浏览器，重复听、重新打开网页后可复用；浏览器可能因空间限制清理缓存。

整组时间轴仍可拖动；跳到尚未缓存的词时，会优先加载目标附近的音频。暂停后拖动仍保持暂停，上一词、下一词、随机与循环播放保留。播放器显示已缓存的词数，全部完成后提示“本组已全部缓存”。此时返回桌面或息屏更稳妥；当前组可临时断网继续播放。请保留浏览器标签页，实际后台及超级岛表现仍由手机系统和浏览器决定。

“跟随单词”默认开启：每次切到下一个词，单词表会滚动，使当前行居中于播放器上方的可见区域；拖动跳听也会立即定位。临时翻看其他词时可取消勾选，重新开启后回到当前词。电脑、手机均适用，最后一个词也能居中。

不支持 MP3 流式音频的浏览器会退回原来的整组准备方式，仍可播放和拖动。用户档案、GitHub 绑定、学习记录、词书及释义保持原状。

实现参考：[Chrome 连续音频流](https://developer.chrome.com/blog/media-source-extensions-for-audio)、[Media Session](https://developer.chrome.com/blog/media-session)。

## 第八版：本机登录与专属学习

已有用户第一次打开新版需补设至少 6 位密码。设置只作用于当前浏览器，保留原有词书、学习记录和 GitHub 绑定。右上角用户菜单可修改密码、切换用户或退出本次登录。同一标签页刷新会保持登录，退出后需重新输入密码；切换用户也需验证该用户密码。手机和电脑分别设置本机密码，不会将密码上传或同步。

原有绑定用户可直接将“我的学习”改名为“何子豪”，不要为此新建空白档案。只有该原有档案登录、用户名为“何子豪”，且成功验证其既有私有 GitHub 仓库后，才显示“单词复习、专业短听短读、面试问答”三个入口。其他用户仍使用原来的单词学习、词书选择和复习。其他浏览器仅输入同名无法取得专属内容。

专属学习包含 50 个专业词组及例句、8 篇原创短听短读及 16 道理解题、10 组面试范本及 30 个独立短段。可整篇听、单段循环、调速、隐藏原文/中文；当前内容随播放定位。面试页可录音回听和下载，录音只留在本次页面，不上传 GitHub，切换页面前如需保留请下载。练习完成标记沿用原有私有仓库同步，用户录音和密码不在同步数据中。

个人范本、专业学习文本及录音放在私有仓库，不包含在公开 Pages 或公共下载包。网页在有权访问时通过 GitHub API 读取，并只在本次页面内存中缓存；退出、改名失去访问条件或断开绑定时清理内容和录音。此本机密码登录不是服务器统一账号，也不承诺加密浏览器磁盘；私有内容的访问边界由 GitHub 仓库权限提供。

新增内容使用提前生成的神经网络合成语音：英文 Andrew Multilingual，中文词义晓晓。播放时不依赖手机系统语音包，不实时调用语音服务。范本不是招聘真题，个人主观表述与未来计划应按本人意愿调整。

## 指定托福词书自然语音升级

“570个单词轻松征服托福”保留源数据实际的 572 条、12 组及原有进度。英文 572 条、中文主释义去重后 559 条，共 1,131 条录音改用 Andrew / 晓晓神经网络语音。升级按词书单独生效，即使词条同时出现在其他书中，也不改动其他书的发音。标题旁显示“自然语音”；点读三遍、整组英文三遍加中文一遍、听选、流式播放和整组拖动均保留。

原始释义不随语音升级修改。多义词的孤立读音仍应结合词性和语境理解；本次没有声称逐词完成真人审音。

# 每日学习热力图（第九版）

2026-10-28

点击右上角个人头像／用户名，首先显示当前用户的每日热力图。手机可横向查看全年，或直接选择日期；账号切换、改名和密码收进下方的账号管理。

## 统计口径

- 不同单词：当天完整听过至少一遍英文的单词去重数。
- 学习次数：一次点读或随身听经过一个词，完整听过一遍即计 1 次；自动三遍属于同一次学习。
- 学习遍数：一次点读自动读三遍，也只算 1 遍；随身听经过一个词同样只算 1 遍。至少完整听到一次英文后计入，主动重播或循环再次经过才增加遍数，不增加当天的不同单词数。已有记录按学习次数重算显示遍数，听音时长不变。
- 听音时长：单词点读、听选、随身听（含专业词组）与专业例句的实际播放时长。音频本身的停顿计入，播放器暂停、缓冲、加载与拖动跳过不计。调速按实际花费时间计算。
- 单独听例句会计入例句时长，并列出对应单词；不冒充完整英文单词听读的次数或遍数。
- 面试回答、短文朗读、自己录音的回放不计入本次“单词＋例句”热力图。

白色为 0，四档绿色分别为不足 5 分钟、5–15 分钟、15–30 分钟、30 分钟以上。每日明细包含单词、中文释义、词书、次数及遍数。统计按设备当地日期归档，跨午夜拆分时长。

## 保存和同步

每个用户独立保存。原有 GitHub 绑定用户同步时自动合并统计；每个页面的累计记录有独立标识，重复同步不重复相加，两个标签页的播放也会合并。导出／恢复学习记录包含热力图。电脑和手机都应刷新到新版，换设备前可点立即同步。

历史版本没有每日播放记录，因此仅从新版开始累计，不根据“已看懂／已听懂”状态回填过去。统计保存于浏览器；关闭页面前结束播放可立即保存，浏览器被系统强制杀掉时可能丢失最后几秒。没有额外上传到第三方统计服务。
