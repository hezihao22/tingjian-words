# 听见单词

以听懂、看懂为目标的单词网站。电脑显示紧凑单词表，手机自动切换为触摸布局。

## 使用

在线地址：https://hezihao22.github.io/tingjian-words/

- 仅保留六级24本、GRE5本、托福9本，共38本词书。
- 每50个词分一组，末组保留剩余词。
- 点击单词读三遍英文；整组播放为英文三遍、中文主要释义一遍。
- 听音选义隐藏英文，选择中文答案；答错或不知道的词加入复习。
- 看懂、听懂分别记录；支持自定义主要释义、导出和恢复学习记录。

## 安卓手机

建议使用 Chrome 或 Edge 打开上方网址，可通过浏览器菜单添加到主屏幕。
网站使用手机系统提供的中英文语音。右上角齿轮可以分别选声音并试听。
若缺少声音，请在安卓系统“文字转语音”设置中安装中英文语音数据，再点击刷新声音。
自动播放从用户点击播放按钮后开始；锁屏、系统休眠或浏览器冻结可能中断。暂停后从当前这一遍的开头继续。

## 记录与数据

学习记录只保存在当前浏览器的 localStorage，不上传服务器。手机、电脑、不同浏览器和不同网站地址之间不会自动同步；可以导出/恢复JSON转移记录。

词书文件以静态JSON按书加载。源数据：[LinXueyuanStdio/DictionaryData](https://github.com/LinXueyuanStdio/DictionaryData)，2026-10-25获取，原Apache-2.0许可证随仓库保留。
本项目对其进行三类词书筛选、书内去重、原文件顺序保留以及中文首义提取。完整原释义仍保留；主要释义并非词频排名，可自行修改。
选定三类共涉及22,955条去重词汇，其中7,364条没有可用中文主要义项，多为短语、专名或源数据缺译。网站明确标注，仍可听英文；补充释义前不参与听选。

## 托管

这是纯静态网站，无需后端、账号系统、API密钥或付费语音服务。
GitHub Pages设置使用 main 分支的根目录，`.nojekyll`保留原文件结构。
所有资源使用相对路径，也可部署在其他静态托管平台的子目录。

核心文件：`index.html`、`style.css`、`app.js`、`core.js`。静态词书位于 `data/books/`。
本地可执行 `python -m http.server 8080`，再访问 http://localhost:8080 。
