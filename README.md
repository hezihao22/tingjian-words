# 听见单词

以听懂、看懂为目标的单词网站。电脑显示紧凑单词表，手机自动切换为触摸布局。

## 使用

在线地址：https://hezihao22.github.io/tingjian-words/

- 包含六级24本、考研42本、GRE5本、托福9本，共80本词书。
- 每50个词分一组，末组保留剩余词。
- 点击单词读三遍英文；整组播放为英文三遍、中文主要释义一遍。
- 听音选义隐藏英文，选择中文答案；答错或不知道的词加入复习。
- 看懂、听懂分别记录；支持自定义主要释义、导出和恢复学习记录。

## 安卓手机

建议使用 Chrome 或 Edge 打开上方网址，可通过浏览器菜单添加到主屏幕。
网站自带中英文 MP3 音频，完全不依赖手机系统语音包。首次播放需要联网，音频按需加载，不会一次下载整个音频库。
手机单词表在主要释义下方，以稍小字体完整显示词库的全部原始释义。
整组播放先准备连续音频，再开始播放；可拖动时间轴，暂停后继续当前位置。后台和息屏播放受系统、浏览器策略影响。

## 用户名与多人使用

右上角用户名按钮可修改当前名称，或创建、切换独立本机用户。每个用户分别保存词书、分组、已看懂、听选结果、收藏、释义和播放设置。导出/恢复仅针对当前用户，导出文件名包含用户名。

升级后原有记录和 GitHub 绑定仍在“我的学习”档案中。你可在自己的电脑和手机 Edge 分别将它改成自己的名字，继续使用已有私有仓库同步，无需新建档案或重新绑定。仅原有档案可使用个人 GitHub 同步；新增档案不读取、不使用、不修改它的授权。标签页切换用户后，其他已打开标签页仍留在各自用户中。

只分享网址不会分享授权。其他人用自己的浏览器打开，即使填写同名，也无法取得你的记录。用户名是本机档案名称，不是带密码的网络账号，不会凭名字跨设备同步。同一个浏览器的使用者可切换本机档案；个人授权只保留在自己的设备。若其他浏览器曾绑定同一个进度仓库，应在那里断开绑定。

## 记录与数据

学习记录先保存在当前浏览器，支持导出/恢复 JSON。设置中的 GitHub 同步可绑定独立私有仓库：使用仅授权该仓库 Contents 读写权限的 Fine-grained token。手机和电脑分别绑定；授权默认仅在当前标签页会话中保留，也可明确勾选记住到个人设备。授权码不会写入进度 JSON、导出文件或公开源码。
同步按字段最近修改时间合并，保存已听懂、已看懂、收藏、自定义释义及其恢复动作、所选词书与分组；播放偏好留在各设备。修改后空闲约20秒同步，页面打开/回到前台时合并，前台每2分钟检查一次。关闭页面前可点立即同步。离线记录保留，恢复联网后重试。请保持设备时间准确。
私有仓库中的 progress.json 只在有变化时提交。首次需创建仓库并授权，GitHub 登录状态不会自动传递给 Pages 网站。

词书文件以静态JSON按书加载。源数据：[LinXueyuanStdio/DictionaryData](https://github.com/LinXueyuanStdio/DictionaryData)，2026-10-25获取，原Apache-2.0许可证随仓库保留。
本项目对其进行四类词书筛选、书内去重、原文件顺序保留以及中文首义提取。完整原释义仍保留；主要释义并非词频排名，可自行修改。
选定四类共涉及28,474条去重词汇，其中4,234条没有可用中文主要义项，多为短语、专名或源数据缺译。网站明确标注，仍可听英文；补充释义前不参与听选。
音频覆盖全部词库英文和已有主要中文释义，共47,228个文件（含两条试听）。由 Windows Zira 英文、Huihui 中文语音预生成，48kbps MP3；同一释义复用一份。手机仅播放音频文件。新编辑的中文若不在音频目录中，保留显示及听选，跳过该条中文朗读，并明确提示。

## 托管

这是纯静态网站，无需后端或付费语音服务。不使用同步时无需账号或授权码。
GitHub Pages设置使用 main 分支的根目录，`.nojekyll`保留原文件结构。
所有资源使用相对路径，也可部署在其他静态托管平台的子目录。

核心文件：`index.html`、`style.css`、`app.js`、`profiles.js`、`core.js`、`sync-core.js`、`sync.js`。静态词书位于 `data/books/`，MP3 位于 `data/audio/`。
本地可执行 `python -m http.server 8080`，再访问 http://localhost:8080 。

## 第六版：整组进度与后台播放

点击“播放本组”或“播放筛选结果”，先等待本 List 的音频准备完成。底部播放器显示整组时间轴，可在手机上拖动、电脑上点击或用键盘调整；拖动时显示对应单词。暂停时调整仍保持暂停；上一词、下一词直接跳到词首。播放结束后保留播放器，可跳回任意位置或点播放重听。随机顺序与循环本组同样支持。

整组播放改为单个连续音频，英文三遍、中文一遍和停顿都已包含在音频里，不再依赖网页计时器逐条切换。准备完成后可返回桌面或息屏，并保留浏览器标签页。已接入标准 Media Session 的标题、词书信息、封面、播放状态、时间位置、播放/暂停、前后跳转及上一词/下一词控制。

推荐在个人手机的 Edge 打开。小米超级岛能否显示，由浏览器和系统决定；红米 K90 Max / 澎湃 OS 4 尚未真机验证。网站不申请额外通知权限，也不需要安装语音包。若后台中断，请检查浏览器的后台运行限制；关闭标签页或清理浏览器进程仍会停止播放。无 Media Session 支持的浏览器仍可在网页内播放和拖动。

首次会加载本组需要的音频，准备时有数量提示并可取消。音频准备好后，当前这一组可暂时断网继续播放；不代表整个词库已离线下载。播放设置和本组准备结果仍留在本设备，学习进度和用户隔离规则不变。

实现参考：[Chrome 媒体会话接口](https://developer.chrome.com/blog/media-session)、[小米超级岛说明](https://dev.mi.com/xiaomihyperos/ability/XiaomiHyperIsland)。
