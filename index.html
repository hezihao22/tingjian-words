内置中英文音频

打开网页、点播放就能听，无需安装或设置手机语音包。首次播放需要联网，播放时请保持页面打开。

个人 GitHub 同步

仅同步当前原有学习档案。授权只保存在你绑定的浏览器中，不随网址分享。电脑和手机的 Edge 各绑定一次即可；新增用户不会继承此授权。

首次使用：三步绑定
  1. 准备你自己的独立私有进度仓库，并添加 README。已有绑定可继续使用，无需重新创建。
  2. 打开 Fine-grained token 设置 ↗，设置有效期，在 Only select repositories 中只选这个进度仓库，将 Repository permissions → Contents 设为 Read and write，然后生成。
  3. 将授权码粘贴在下方，点击“绑定并同步”。手机和电脑填写同一个仓库；可以各建一个授权码。

不要把授权码发到聊天里。它只用于本网站直接访问 GitHub。若勾选“记住授权”，它会保存在此浏览器中；请仅在自己的设备上勾选。到期后需换新授权码。

尚未绑定，学习记录照常保存在本机。

自动同步会在操作停止约 20 秒后进行；换设备前可点“立即同步”。两端记录按每项最近修改时间合并，请保持设备时间准确。播放速度等偏好各设备独立保存。

此用户使用独立本机档案，不使用原有用户的 GitHub 授权。换书和学习不会改动其他用户的记录；可导出文件在另一台设备恢复。

学习用户

每个用户分别保存词书、分组、学习进度和释义。切换时会停止播放。

用户名是此浏览器中的档案名称，无需注册，也不是密码登录。其他设备输入同名不会自动同步或取得你的授权。同一浏览器的使用者可以切换本机档案，公共设备请勿保存个人授权。
